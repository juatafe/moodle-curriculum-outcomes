# Next steps

The next milestone should be controlled external testing of `0.4.0-dev` before any alpha promotion.

1. Add browser coverage for BOE fixture import, archive/delete safety, safe undo, native rubric authoring/grading and direct-URL role denial.
2. Characterise restore merge into an existing course; keep it unsupported until collision semantics are demonstrably non-destructive.
3. Consider a DOGV/GVA provider using only documented machine-readable sources.
4. Evaluate opt-in source monitoring and teacher-facing provenance freshness alerts.
5. Refine accessibility and filtering for large curricula without changing import semantics.
6. Add CI for the public repository with a deliberately maintained Moodle/database matrix.
